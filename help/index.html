Getting Started

The basic Flowless workflow for end users.

How do I open Flowless?

Open the Flowless Web App using the link provided by your administrator.

If you also have access to the Flowless spreadsheet, you may be able to use Flowless → Open Web App from the spreadsheet menu.

How do I upload a file?
  1. Open the Upload tab.
  2. Enter your name.
  3. Search for and select the project.
  4. Choose a file or drag and drop it into the upload area.
  5. Click Upload file.
When the upload finishes, Flowless shows an Upload complete message.
How do I find project files?
  1. Open the Finder tab.
  2. Search by Project ID or project name.
  3. Select the project.
  4. Choose View files or Open folder.

Use Refresh files if the file list looks out of date.

Projects

Finding, creating, and understanding project status.

The project I need is not listed.

First select Refresh project list.

If the project still does not appear, it may not be Active yet. Contact your administrator, or create a new project request if it is genuinely a new project.

How do I create a new project?
  1. Type the intended project name into Select Project.
  2. If no matching project exists, choose Create new project.
  3. Confirm the Project Name. Flowless assigns a temporary Project ID.
  4. Choose a file and upload it.
The new project remains Pending until an administrator approves it.
What does Pending mean?

Pending means the project was created from the Web App and is waiting for administrator review.

Pending projects are not shown in normal Upload or Finder searches. After approval, the project becomes Active.

What is the difference between Active and Inactive?

Active projects are available in Upload and Finder searches.

Inactive projects remain in the project master but are hidden from normal end-user search.

Files

Duplicate filenames, versions, and project folders.

What happens if the same filename already exists?

Flowless asks you how the file should be saved:

  • Replace existing file — replace the existing file.
  • Save as new version — keep both files and add a version suffix such as _v1 or _v2.
  • Cancel — do not upload the file.
Can I check files before uploading?

Yes. After selecting an existing project, choose Check existing files to see what is already stored in that project folder.

How do I open the project folder in Google Drive?

Open Finder, select the project, then choose Open folder.

Why is Folder_URL blank for a project?

A project can be registered before its Drive folder exists. In that case, Folder_URL remains blank.

The project folder is created and the URL is registered when a file upload first needs that folder.

Notifications

How Flowless email notifications work.

Who receives upload notifications?

Notifications are sent to users who are registered for notifications by the Flowless administrator.

The Notify setting controls whether a user is included in notification recipients.

I did not receive a notification email.
  • Check your spam or junk folder.
  • Confirm that your administrator has enabled Notify for your user record.
  • Ask the administrator to verify the email address in Master_Users.
Will I be notified when a Pending project is approved?

Flowless can send an approval notification when a Pending project becomes Active. The administrator can choose whether to send the notification during approval.

Admin

Common setup and administration questions.

How do I open the Admin Sidebar?

Open the Flowless spreadsheet and choose Flowless → Open Admin Sidebar.

Do I have to configure a Parent Folder?

No. You can set a Google Drive folder in Admin Sidebar → Settings → Parent Folder, but it is optional.

If it remains blank, Flowless can create its default parent folder when the first upload needs one.

You can paste either a Drive folder ID or a full folder URL.
How do I add users?

You can add one user at a time from Admin Sidebar → Users.

For bulk entry, paste User_Name and Email into Master_Users. Flowless automatically fills the Notify checkbox, default Role, and Created_At.

How do I add projects in bulk?

Paste Project_ID and Project_Name into Master_Projects.

If Status and Created_At are blank, Flowless automatically sets Status = Active and fills Created_At.

Folder_URL stays blank until a file upload creates or confirms the project folder.

How do I approve a Pending project?
  1. Open Admin Sidebar → Pending.
  2. Select the Pending project.
  3. Review the uploaded file if needed.
  4. Enter the Final Project ID and confirm the Project Name.
  5. Choose whether to rename the Drive folder and send a notification.
  6. Click Approve and Activate.
How do I deactivate or reactivate a project?

Open Admin Sidebar → Projects, search for the project, then use Activate Selected or Deactivate Selected.

Troubleshooting

Quick answers for the most common problems.

Open Web App is not shown in the Flowless menu.
  1. Confirm that the Apps Script project has been deployed as a Web App.
  2. Open the deployed Web App URL once.
  3. Return to the spreadsheet and reload the page.
The upload failed.

Confirm that a project and file are selected, then try again.

If the problem continues, send the displayed error message to your Flowless administrator.

A project does not appear in Finder.

Select Refresh project list. Finder only shows Active projects.

If the project is Pending or Inactive, an administrator must change its status before it appears.

The project folder cannot be opened.

Refresh the project list and try again. If the issue continues, ask the administrator to verify the project's Folder_URL and Drive access.

I see “Parent Folder is not configured.”

This means no parent folder has been configured yet.

Flowless can create its default Flowless Files folder automatically when the first upload needs a parent folder.

For normal users, no action is usually required.
